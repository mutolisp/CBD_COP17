# CBD COP17 文件中英對照檢閱

《生物多樣性公約》第 17 屆締約方大會（COP17，2026 年 10 月 19–30 日，亞美尼亞葉里溫）會議文件的英文原文與正體中文翻譯對照，附白話摘要。
內容包括 COP 17、卡塔赫納議定書 CP-MOP 12、名古屋議定書 NP-MOP 6 的會中文件（L 文件、CRP、non-paper），以及會前正式文件的摘要。

## 使用方式

- 線上：GitHub Pages 開啟後，網址為 `https://mutolisp.github.io/CBD_COP17/`。
- 本機：直接用瀏覽器開啟 `index.html` 即可，不需要伺服器。
- 英文依段落重排（只合併 PDF 斷行，不改文字；表格保留原版面）。滑過或點選中文段落時，對應的英文段落會以黃色螢光標示；選取中文詞彙時，英文對應詞會以粗體洋紅色標示（依翻譯用語表、決議動詞、外交部國名與數字比對）。
- 固定用語（翻譯用語表、原文對照、外交部國名）在中英文都加底線，滑鼠移到上面會顯示另一語言的對應詞；可用「用語底線」按鈕關閉。左側文件清單可用左上角按鈕收合。
- 過去決議編號（如 15/4、XII/17、CP-10/4、NP-5/3、BS-V/11）連到 CBD 官方原文。每個連結都已連線確認：決議 PDF 須出現該編號；早期決議沒有 PDF，改連 CBD 決議頁，並確認頁面標題相符。查不到的編號不加連結。本屆決議（17/…）尚未發布，所以沒有連結。
- 「KMGBF 目標與說明」頁（左側清單上方）收錄昆明－蒙特婁全球生物多樣性綱要的 2050 年願景、2030 年使命、4 項長期目標與 23 項行動目標。英文為決議 15/4 附件原文，旁附本團的非官方中文翻譯與白話說明，並列出各目標的主要指標，以及本站哪些文件、哪幾頁提到該目標。文件中的「Target 3」「目標 3」也可點回此頁。
- 圖表可用鍵盤操作（Tab 選取、Enter 或空白鍵點選）；手機上寬圖可在圖內左右滑動。
- 「預算與分攤」頁（左側清單上方）把三份預算文件與過去的預算決議（14/37、15/1、15/34、16/28、CP-11/11、NP-5/12）整理成以下內容，每張圖都連回原文頁與 CSV：
  - 資金流向圖；
  - 各國分攤排名；
  - 2019–2028 趨勢；
  - 世界地圖（分攤額、調整後比例、與上一期增減）；
  - 依組成部分與支出類別的小倍數趨勢圖（變化率比較首尾兩年期合計，避免受大會年份影響）；
  - 核定不等於到位：2025–2026 收款率與自願基金到位率、預算執行差額、分攤集中度（洛倫茲曲線；資料來自 CBD/COP/17/3）；
  - 自願信託基金需求對應 KMGBF 目標（旭日圖、目標輪、長條圖）；
  - Yerevan Pathway（全球審查決議草案 L.15 第 14–49 段）與預算的對照；
  - 單一締約方查詢；
  - 互動表格。
- `csv/` 收錄全部會議文件的表格，每張表一個雙語 CSV，說明見 `csv/README.md`。文件頁上有表格的頁面，頁首會顯示 CSV 下載連結。
- 點任一中文段落或白話摘要即可修正，修正會暫存在瀏覽器。到「待送出修正」可以：
  - **送出 GitHub Issue**：需要 GitHub 帳號，Issue 內容會公開；
  - **下載 JSON**：寄給維護者。

## 維護流程

產生器與翻譯工具在臺灣代表團 App 專案（`cop17-app/tools/`）：

```sh
# 1. 從 Issue 複製 JSON 存成 fixes.json，套用（會擋簡體字、外文、中國大陸用語與不唯一的原文）
python tools/cbd_docs.py review-apply fixes.json
python tools/cbd_docs.py summary-apply fixes.json
# 2. 查新出現的決議編號連結、重新抽表與檢查，再重新產生網站（含 csv/）
python tools/decision_links.py
python tools/tables.py extract && python tools/tables.py check
python tools/tables.py history   # 過去預算決議（需要時）
python tools/review_site.py --out ../CBD_COP17
# 3. commit、push
```
